# Priya's Fashion Hub – Meesho Seller Website

A complete, working e-commerce website for a Meesho seller to have their own branded online store.

## 🛍️ Features

- **Home Page** – Hero section, trust badges, shop-by-category, featured products, bestsellers, promotional banner, customer testimonials
- **Products Page** – Full catalog with category filters, price range slider, sort options (featured/price/rating/discount), search, mobile filter drawer
- **Product Detail Page** – Image gallery with thumbnails, color & size selectors, quantity picker, add-to-cart with variant tracking, related products
- **Shopping Cart** – Persistent cart (localStorage), per-variant quantity controls, discount + delivery calculation, payment method options
- **About Page** – Brand story, values, stats
- **Contact Page** – Contact info, FAQ accordion, contact form

## 🚀 Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## ��️ Tech Stack

- **Framework**: Next.js 16 (App Router, TypeScript)
- **Styling**: Tailwind CSS 3
- **State**: React Context + localStorage for cart persistence
- **Icons**: Lucide React
- **Build**: Turbopack
